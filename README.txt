# FinanceFlow - Personal Expense Tracker

A modern Personal Expense Tracker built using only:
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Features
- Modern responsive finance dashboard
- Income, expense and balance cards
- Savings-rate calculation
- Income vs Expense six-month chart
- Expense category donut chart
- Recent transactions
- Add, edit and delete transactions
- Search and filters
- Monthly budgets with progress tracking
- Financial goals with savings progress
- Reports and monthly summaries
- Dark mode
- LocalStorage persistence
- Mobile-friendly layout

## How to run
1. Extract the folder.
2. Open `index.html` in Chrome/Edge.

For the best experience, you can also use VS Code Live Server.

## Data
All data is stored locally in the browser using LocalStorage. No backend or database is required.

## Main files
- `index.html` - application structure
- `style.css` - complete UI styling and responsive design
- `script.js` - application logic, charts, LocalStorage, transactions, budgets and goals
